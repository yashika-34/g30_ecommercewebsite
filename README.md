> A Nykaa-inspired beauty e-commerce web application built with **Flask (Python)** — featuring product listings, user authentication, shopping cart, and order management using server-side session handling.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔐 **User Auth** | Login/register with session management |
| 🛍️ **Product Catalogue** | Browse beauty products (Lipstick, Foundation, Eyeliner, etc.) |
| 🛒 **Shopping Cart** | Add/remove items, quantity management |
| 📦 **Order Flow** | Place and track orders |
| 🎨 **Flask Templates** | Jinja2-based server-side rendering |

---

## 🗂️ Project Structure

```
g30_ecommercewebsite/
```

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| **Backend** | Python 3.8+, Flask |
| **Templating** | Jinja2 (Flask render_template) |
| **Auth** | Flask session management |
| **Data** | In-memory product & user store (dev) |

## ▶️ Quick Start

```bash
# 1. Clone
git clone https://github.com/yashika-34/g30_ecommercewebsite.git
cd g30_ecommercewebsite

# 2. Install Flask
pip install flask

# 3. Run
python app.py
# App at http://127.0.0.1:5000
```
